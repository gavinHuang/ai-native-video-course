# AI-Native Video Content Creation

In this program, AI is the production medium. You use it to write, design, generate, edit, finish, and deliver video. You also learn how the models work inside, how to connect them into pipelines that agents operate, and how to run the infrastructure under them.

The program is for adults with IT experience. You already use a command line, Python, APIs, and cloud services. You do not need any experience with video, film, or design.

**How each module works:** read the concept text, look at the diagram, listen to the summary, and watch the selected videos. Then follow the worked example and do the lab. Use the quiz to check yourself, and compare your result with the model answer. Mark the module complete. Your progress stays in this browser.

> **Concepts last; tools change.** The concept text uses no product names. The labs name the best current tools as of October 2026. One example: OpenAI removed the Sora 2 API on 2026-09-24, so any pipeline that used only that API stopped. In this program you learn to design for change.
