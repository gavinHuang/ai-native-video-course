## About this course

This field changes every month. The skill that lasts is the ability to learn the next thing fast and correctly. This course gives you that method, and a map of where the field is going.

**Starter tools for this course** (in the [starter kit](starter.zip); tested on 2026-10-04):

| Tool | Use |
|---|---|
| `tools/arxiv_watch.py` | Pass 0: new arXiv papers for your keywords as a Markdown checklist (M01, M03) |
| `templates/production_note.md` | The production-note template: claimed, shown, evidence, decision (M01) |
| `tools/model_trial.py` | One-day model test: usable rate with intervals, Fisher test, cost per usable second, a suggested decision per shot type (M02) |
| `examples/example_scores_10.csv`, `example_scores_30.csv` | Simulated score sheets for the M02 worked example |
